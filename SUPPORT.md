# Support

## How to file issues and get help

This project uses GitHub Issues to track bugs and feature requests. Please
search the existing issues before filing a new one to avoid duplicates. For
new issues, file your bug or feature request as a new Issue.

For help and questions about using this project, please reach out to the
repository owner listed in the [README](README.md).

## Support Policy

This repository is **demonstration content** for the AI Genius S5E2 session.
It is provided as-is, with no service-level commitment. Support is limited to
the resources listed above and is offered on a best-effort basis.

For questions about the underlying products rather than this demo, use their
official channels:

| Topic | Where to go |
|:------|:------------|
| GitHub Copilot SDK | [github/copilot-sdk](https://github.com/github/copilot-sdk) |
| GitHub Copilot CLI | [GitHub Copilot docs](https://docs.github.com/copilot) |
| .NET / ASP.NET Core | [dotnet/aspnetcore](https://github.com/dotnet/aspnetcore) |
